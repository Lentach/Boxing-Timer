# Nowy Projekt

Prosty szablon projektu HTML, CSS i JS.

## Struktura
- `index.html` — główny plik HTML
- `style.css` — style
- `app.js` — logika JS

## Uruchomienie
Otwórz `index.html` w przeglądarce.

## Instalacja npm
Projekt korzysta z npm do zarządzania zależnościami (jeśli będą potrzebne).

```bash
npm install
```
